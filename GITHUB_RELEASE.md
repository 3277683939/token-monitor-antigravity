# Token Monitor v1.0.0 (Antigrative Dashboard Edition)

Token Monitor v1.0.0 is the customized Antigravity built-in plugin edition with ⚡ TM capsule branding, pulsing live connection status indicator, purple-blue glassmorphism cards, synchronized `v1.0.0` Desktop + IDE packages, and automatic self-update & periodic upstream sync checking against `3277683939/token-monitor-antigravity`.

## Install or update

- Standalone IDE: download `antigrative-dashboard-ide-1.0.0.vsix` and choose **Install from VSIX…** in the IDE extensions view. Fully quit the IDE and restart using `--remote-debugging-port=0 --remote-debugging-address=127.0.0.1`.
- Desktop App: context details → **⋯ → Check for updates**, or extract `antigrative-dashboard-1.0.0.zip` and run `python manage.py install` (`python3` on Linux/macOS).
- CLI: update the adapter using the included installer if needed.

Existing statistics and settings are retained. SHA-256 files accompany both packages.
